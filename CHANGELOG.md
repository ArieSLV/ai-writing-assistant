## [1.0.0] - 2026-08-29

### Added

- Global clipboard proofreading with Gemini or Ollama.
- Global translation to English with Gemini or Ollama.
- Gemini smart voice transcription with a dedicated API credential.
- Movable recording overlay with live waveform and elapsed time.
- Tray-based processing, success, failure, and cancellation states.
- Local and remote audio cleanup on terminal paths.
- Automated CI, dependency updates, and self-contained Windows releases.
