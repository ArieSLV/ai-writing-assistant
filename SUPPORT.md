# Support

Use [GitHub Discussions](https://github.com/ArieSLV/ai-writing-assistant/discussions) for setup questions and general usage help. Use the issue templates for reproducible bugs and feature requests.

Before asking for help:

1. Check the README troubleshooting guidance.
2. Confirm the application version, Windows version, and selected provider.
3. Remove API keys, clipboard contents, transcripts, and private paths from logs or screenshots.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).
